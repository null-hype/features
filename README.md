# features

Install [Witness](https://github.com/null-hype/witness) in a Dev Container:
verification findings appear on their source, with navigation to the evidence.

The feature installs the Witness language server, its Neovim client, and a
recorded example run. It builds Witness from one selected ref so the server,
client, and example stay together. Go is supplied by the Go feature dependency;
Neovim is installed if absent.

Witness owns the findings contract and editor behaviour. This repository owns
environment setup and headless installation checks, including the remote user.

## Try it from source

With Docker and the Dev Container CLI installed, run:

```sh
git clone https://github.com/null-hype/features.git
cd features
devcontainer features test -f witness --skip-autogenerated --skip-duplicated .
```

The scenario checks that Witness is on PATH and that Neovim displays the
example finding and navigates to its evidence as the container's remote user.
The `version` option selects a Witness tag, branch, or full commit SHA
(default: `v0.1.0`). See the [manifest](src/witness/devcontainer-feature.json)
and [installer](src/witness/install.sh).

## Boundaries

[worlds](https://github.com/null-hype/worlds) captures delivery evidence;
[Witness](https://github.com/null-hype/witness) presents findings;
Features installs Witness. These components grew out of the
[agent-plugins research lab](https://github.com/null-hype/agent-plugins).
